From references to a complete reel

One reusable skill. Two workflows, selected by the inputs you actually have. Photos-only requests do not require a source video or control maps.

Source video supplied

Ref + ControlNet

Reconstruct motion and shot order using face/body references and one to three full-frame scene anchors. The source drives depth and DWPose, with mandatory TS Pose Keypoint Smoother.

Strength: stronger guidance for the measured motion and scene sequence.

Tradeoff: extra models, preprocessing and exact alignment; conflicting references can still cause artifacts.

Photos + text

Ref Only

Create a new action from one to five useful photos and a complete prompt. Length and output FPS are direct values. No source clip, pose/depth, ControlNet, TS smoother or source audio.

Strength: fewer dependencies and no control preprocessing.

Tradeoff: looser motion and scene continuity; artifacts remain possible. A speed advantage has not been benchmarked for this new graph.

Install the skill

  1. Download or clone the repository.
  2. Copy the entire skills/minimax-h3-reel-maker directory into your agent's skills directory: %USERPROFILE%/.codex/skills/ for Codex, or %USERPROFILE%/.claude/skills/ for Claude Code. Keep SKILL.md, assets, references and scripts together.
  3. Start a new session and invoke $minimax-h3-reel-maker in Codex or /minimax-h3-reel-maker in Claude Code. Supply the actual file paths and your requested action.

Skill instructions · Models, custom nodes and setup · Complete prompt example

Model weights and private media are not bundled. The templates retain a disabled KJNodes attention node, so both supplied graphs require KJNodes. Only the source-video graph requires H3-FunControl, controlnet_aux, Teskor's Utils and the control models.

Prepare a render

  1. Inspect the actual references. Assign each connected Picture a role. Keep native source resolution and the requested wardrobe, props and scene.
  2. Write a complete English prompt using the bundled prompting guide. Replace all template text; match Picture numbering to the connected images.
  3. Run the local helper from the installed skill directory. It uses Python and Pillow, plus ffprobe for source mode. It creates a fresh package and does not submit jobs.
python scripts/configure_workflow.py --images "D:\my_reel\portrait.png" --prompt "D:\my_reel\prompt.txt" --frames 124 --slug reel01_attempt01 --out "D:\my_reel\package01"

For source reconstruction, add --source with a correctly aligned video and list face, body and scene images after --images. The setup guide includes the full command and alignment example.

What was verified

The source-mode graph descends from an accepted real render. Both new packages were prepared from real local inputs and their graph wiring and media were checked. The photos-only graph has no source-derived FPS, length or audio dependency.

No new GPU render was performed for this delivery. The pure photos-only graph and the recipient's installation are not GPU-validated. The recorded source baseline used ComfyUI 0.34.0 and an RTX PRO 6000 Blackwell Max-Q with approximately 96 GiB VRAM; this is not a minimum requirement.

If a reference-generation tool refuses an image, preserve the exact prompt and returned error and report the missing asset. Do not silently redesign the reference or conceal the refusal.
